## Physics Study with Verlet Integration

### Objective: Implement a PBD system.

PBD: Particle Based Dynamics, with Verlet integration

a basic implementation of the verlet integration for the dynamics evaluation of particles, without using Unity Physics system.
Sticks and Springs have been added to make the particles interact.

Currently with no collision detection, particles can't leave the area due to positional constraints.

RigidBody-like behaviour emerges from just simple rules applied to particles and sticks.

Currently working on impulse implementation.
